REFERENCE · 65 TERMSSystem Terminology & Architecture Dictionary

Plain-English definitions of every database concept, protocol, server role, security control, mail feature, and testing tool used in Couriva WebMail.

Database & Schema

ACID (Atomicity, Consistency, Isolation, Durability)

Guarantees that database transactions—like delivering a message to multiple recipients and updating quota—either succeed completely or roll back cleanly so partial or corrupted mail never occurs. Enforced by MariaDB's InnoDB engine.

Database & Schema

InnoDB

MariaDB's default transactional storage engine. Provides ACID transactions, row-level locking, crash recovery, and foreign-key constraints across all 14 Couriva tables.

Database & Schema

MariaDB 10.11

Open-source relational database server running locally on 127.0.0.1:3306 on Windows Server 2022, storing users, emails, recipients, attachments metadata, labels, folders, and audit logs.

Database & Schema

PDO & Prepared Statements

PHP Data Objects (PDO) database abstraction layer using parameterized prepared statements (?) everywhere so user input can never alter SQL structure (prevents SQL injection).

Database & Schema

Foreign Keys & ON DELETE SET NULL

Database referential integrity constraints linking emails, attachments, labels, and folders; ON DELETE SET NULL preserves audit/sender snapshots even if a user row is removed.

Database & Schema

14-Table Schema (webmail)

Core database tables: users, emails, email_recipients, attachments, contacts, drafts, scheduled_emails, folders, labels, email_labels, notifications, blocked_senders, spam_reports, and system_logs.

Database & Schema

Migrations (001–007)

Ordered, versioned SQL scripts in database/migrations/ that evolve the database schema safely (e.g., 006_ad_object_guid.sql, 007_email_category.sql).

Database & Schema

Idempotency Key

Unique key stored in delivery_status so retrying a send or scheduled job never creates duplicate message deliveries.

Database & Schema

SQLite (Test Harness)

Lightweight in-memory/file database used by offline PHP test suites (ad_ou_policy_test.php, admin_protection_test.php) to run fast isolated checks without touching production MariaDB.

Identity & Active Directory

AD DS (Active Directory Domain Services)

Microsoft directory service on Windows Server 2022 acting as the authoritative identity store for couriva.com user accounts, passwords, and organizational units.

Identity & Active Directory

LDAPS (LDAP over TLS, Port 636)

Encrypted Lightweight Directory Access Protocol connection using TLS/SSL on TCP port 636 so domain passwords and directory queries are never sent in plaintext.

Identity & Active Directory

StartTLS (Port 389)

Upgrades a plaintext LDAP connection on port 389 to an encrypted TLS session before binding credentials; enforced alongside TLS_REQCERT demand.

Identity & Active Directory

TLS_REQCERT demand (ldap.conf)

OpenLDAP client directive in C:\openldap\sysconf\ldap.conf requiring strict certificate validation against the Trusted Root CA before any LDAPS bind succeeds.

Identity & Active Directory

Trusted Root CA (Certificates MMC)

Local Windows Certificate Authority root certificate installed in the server's Trusted Root Certification Authorities store so PHP/OpenLDAP trusts LDAPS 636.

Identity & Active Directory

OU (Organizational Unit)

Active Directory container used to scope access and roles: OU=CourivaUsers permits Couriva sign-in, while sub-OU OU=CourivaAdmins automatically assigns admin role on login.

Identity & Active Directory

Distinguished Name (DN)

Full hierarchical AD path of an object (e.g. CN=Admin Spare,OU=CourivaAdmins,OU=CourivaUsers,DC=couriva,DC=com) used for exact bind and OU verification.

Identity & Active Directory

objectGUID (ad_object_guid)

Immutable 16-byte UUID assigned by Active Directory to every user object. Couriva stores it in users.ad_object_guid so AD email or name changes never hijack or duplicate local accounts.

Identity & Active Directory

sAMAccountName & UPN

sAMAccountName is the short Windows logon name (e.g. seno); UPN (User Principal Name) is the email-style logon (e.g. seno@couriva.com). Couriva validates the email domain against LDAP_DOMAIN.

Identity & Active Directory

userAccountControl (0x0002)

AD bitmask attribute checked at login; bit 0x0002 (ACCOUNTDISABLE) immediately blocks disabled AD accounts from signing in.

Identity & Active Directory

Service Account (svc_couriva)

Dedicated low-privilege AD account configured via LDAP_BIND_DN / LDAP_BIND_PASSWORD to search OU=CourivaUsers before re-binding as the authenticating user.

Identity & Active Directory

Break-Glass Local Admin

Emergency local administrator created via CLI (php bin/create-admin.php) with auth_source='local', allowing admin sign-in even if Active Directory is unreachable.

Web Server & Runtime

Windows Server 2022

Host operating system running all Couriva infrastructure roles: IIS 10, AD DS, DNS, MariaDB 10.11, and Windows Task Scheduler.

Web Server & Runtime

IIS 10 (Internet Information Services)

Windows web server hosting Couriva on ports 80/443, handling TLS termination, URL Rewrite, Request Filtering, and FastCGI PHP execution.

Web Server & Runtime

Application Pool (CourivaPool)

Isolated IIS worker process boundary running Couriva's PHP FastCGI handlers with scoped NTFS permissions.

Web Server & Runtime

FastCGI (php-cgi.exe)

Persistent process interface between IIS 10 and PHP 8.2 that reuses worker processes for low latency instead of spawning a new PHP process per request.

Web Server & Runtime

PHP 8.2

Server-side language powering Couriva's MVC controllers, models, services, and CLI scripts (bin/create-admin.php, bin/process_scheduled.php).

Web Server & Runtime

URL Rewrite

IIS module configured in web.config to enforce HTTPS on domain hostnames while routing clean paths and exempting local/private lab IPs when needed.

Web Server & Runtime

Request Filtering (404.7 / 404.8)

IIS security filter blocking direct HTTP access to sensitive segments (/config, /database, /storage, .env, .sql) before PHP executes.

Web Server & Runtime

NTFS ACL

Windows filesystem permissions restricting write access exclusively to storage/logs and storage/attachments while keeping application code read-only to IIS.

Web Server & Runtime

Windows Task Scheduler & flock()

Runs bin/process_scheduled.php every minute; flock() provides an atomic OS file lock so concurrent runs never double-send scheduled emails.

Web Server & Runtime

Machine Environment Variables

System-wide Windows variables (DB_*, LDAP_*, MAIL_*) read by PHP via getenv() so secrets never need to be hardcoded in repository files.

Web Server & Runtime

Event Viewer & system_logs

Windows Event Viewer captures OS/IIS/AD events, while Couriva's system_logs table records application-level logins, failures, password changes, and admin actions by IP.

Application Security

CSP (Content-Security-Policy) + Nonce

HTTP response header restricting which scripts, styles, and resources the browser may execute. Couriva emits a single authoritative CSP with a per-request cryptographic nonce in includes/functions.php.

Application Security

CSRF (Cross-Site Request Forgery) Token

Per-session secret token verified on every POST form and JSON API mutation to prevent unauthorized third-party sites from triggering actions on a logged-in user's behalf.

Application Security

session_epoch

Integer counter on each user row incremented on password change, role change, or account disable—immediately invalidating all older browser sessions.

Application Security

HttpOnly & SameSite=Strict Cookies

Session cookie flags preventing JavaScript (document.cookie) from reading the session ID (HttpOnly) and blocking cross-site cookie transmission (SameSite=Strict).

Application Security

HSTS (Strict-Transport-Security)

HTTP header instructing browsers to always use HTTPS for the domain (max-age=31536000; includeSubDomains).

Application Security

X-Content-Type-Options (nosniff)

Prevents browsers from MIME-sniffing responses away from the declared Content-Type.

Application Security

X-Frame-Options (SAMEORIGIN)

Prevents clickjacking by disallowing external sites from embedding Couriva inside an iframe.

Application Security

Referrer-Policy & Permissions-Policy

Referrer-Policy limits leaked URLs on navigation; Permissions-Policy disables unused browser hardware APIs (camera, microphone, geolocation, usb).

Application Security

bcrypt (PASSWORD_BCRYPT)

Adaptive salted password-hashing algorithm used for local accounts so plaintext passwords are never stored.

Application Security

finfo_file() & MIME Allow-List

Server-side PHP file-inspection function that reads magic bytes (not just filename extensions) to reject prohibited uploads like .php scripts.

Application Security

XSS & HTML Escaping (e())

Cross-Site Scripting defense using htmlspecialchars() wrapper e() on every dynamic output in PHP templates.

Application Security

Fail-Closed Policy

Security design where any missing configuration, TLS failure, OU mismatch, or invalid token rejects access rather than falling back to insecure defaults.

Application Security

Protected Admin Guard

Web UI restriction in admin/users.php and admin/edit-user.php blocking modification, demotion, or deletion of admin accounts via browser requests.

Messaging & Features

To / Cc / Bcc

Standard email addressing fields: To (primary recipients), Cc (carbon copy, visible to all), and Bcc (blind carbon copy, hidden from other recipients).

Messaging & Features

Reply / Reply All / Forward

Threading actions preserving parent_email_id; Reply All targets sender + Cc while Forward copies message body and attachments to new recipients.

Messaging & Features

Draft Autosave (30s)

Background JavaScript timer saving compose progress to the drafts/emails table every 30 seconds without losing work.

Messaging & Features

Scheduled Send

Queues an email in scheduled_emails for future delivery (1 minute to 1 year ahead), dispatched by Task Scheduler.

Messaging & Features

Category Tabs (Primary / Promotions / Updates)

Inbox tabs backed by emails.category ENUM and Email::classifyCategory() so messages filter cleanly by category.

Messaging & Features

Archive / Snooze / Star / Trash

Mailbox lifecycle states: Archive hides from Inbox without deleting; Snooze hides until snoozed_until; Star flags important mail; Trash soft-deletes with restore.

Messaging & Features

Privacy-Isolated Spam Reporting

Allows users to report a specific message to admin/spam-reports.php without exposing the rest of their private mailbox to administrators.

Messaging & Features

Blocked Senders

Per-user block list (blocked_senders) that automatically routes future mail from blocked addresses into the recipient's Spam folder.

Messaging & Features

Storage Quota (500 MB)

Per-user attachment storage limit tracked in the sidebar progress bar and enforced before accepting new uploads.

Networking & Defense Lab

Simulated LAN (/28 Subnet)

Isolated 172.20.10.0/28 network configured on the Windows Server VM (172.20.10.2) and host (172.20.10.3) so defense panelists can connect and test without external internet.

Networking & Defense Lab

DNS A Record

Maps domain names (couriva.com, www.couriva.com, mail.couriva.com) to the Windows Server IPv4 address (172.20.10.2) on the local DNS server.

Networking & Defense Lab

NAT vs. Bridged VMware NIC

VMware network modes: Bridged attaches the VM directly to the host's physical/LAN subnet (172.20.10.x), while NAT uses a private host-only/VMnet8 subnet (172.16.13.x).

Networking & Defense Lab

Windows Firewall Rules

Inbound rules permitting TCP 80 (HTTP), TCP/UDP 443 (HTTPS), and UDP/TCP 53 (DNS) while keeping MariaDB (3306) and LDAPS (636) internal.

Networking & Defense Lab

SSH / SCP Deployment

OpenSSH key-based file transfer (scp) and remote PowerShell administration used to deploy updates and run migrations on the Windows Server VM.

Testing, Tooling & Stack

E2E (End-to-End) Testing

Automated full-browser verification (via agent-browser) testing real user flows—login, mail send/reply/forward, attachments, RBAC, and mobile layout—against the live server.

Testing, Tooling & Stack

agent-browser

Headless Chromium CLI automation tool used to run multi-session E2E tests (User A, User B, Admin), capture screenshots, and measure Web Vitals.

Testing, Tooling & Stack

WCAG AA & axe-core

Web Content Accessibility Guidelines (Level AA) audited automatically by axe-core for color contrast (>=4.5:1), ARIA labels, heading hierarchy, and <main> landmarks.

Testing, Tooling & Stack

Web Vitals (TTFB & CLS)

Performance metrics measured during E2E: Time to First Byte (17.8 ms observed) and Cumulative Layout Shift (0 observed).

Testing, Tooling & Stack

Bootstrap 5 & Bootstrap Icons

Locally hosted frontend UI framework and icon set (zero external CDN dependency for offline LAN operation).

Testing, Tooling & Stack

Git, GitHub & Vercel

Version control (Couriva_WebMail_system for app source; Couriva_WebMail_system_GUIDE for static multi-page documentation auto-deployed on Vercel).
